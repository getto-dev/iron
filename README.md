# GymPro Trainer — PWA

Научно обоснованный персональный тренер для тренажёрного зала. Расчёт программ тренировок по стандартам **ACSM** (American College of Sports Medicine) с адаптацией под фармакологический статус атлета.

## Возможности

### Анкета тренирующегося
- **Пол**: Мужской / Женский (с физиологической корректировкой нагрузок)
- **Статус**: 🌿 Натурал / ⚗️ Химик (Enhanced)
- **Антропометрия**: вес, рост, расчёт ИМТ
- **1ПМ** в трёх базовых упражнениях: жим лёжа, присед, становая тяга
- **Калькулятор 1ПМ** по формуле Эпли: введите рабочий вес и количество повторений → автоматически рассчитается 1ПМ и подставится в нужное поле
- **Цель**: Гипертрофия / Сила / Выносливость

### Научный алгоритм расчёта (ACSM)
Программа использует точные диапазоны интенсивности, подтверждённые мета-анализами (Schoenfeld 2017 и др.):

| Цель | Статус | % 1ПМ | Подходы | Повторы | Отдых |
|------|--------|-------|---------|---------|-------|
| Гипертрофия | Натурал | 65-80% | 3-5 | 6-12 | 90-120 сек |
| Гипертрофия | Химик | 70-85% | 4-6 | 6-12 | 60-90 сек |
| Сила | Натурал | 85-95% | 4-5 | 3-5 | 2-3 мин |
| Сила | Химик | 87-97% | 5-6 | 2-5 | 1.5-2.5 мин |
| Выносливость | Натурал | 50-65% | 2-3 | 12-20 | 45-60 сек |
| Выносливость | Химик | 55-70% | 3-4 | 12-20 | 30-45 сек |

**Корректировки**:
- Для женщин: −2.5% к интенсивности базы, +1-2 повторения
- Для химиков: увеличенный объём (на 1-2 подхода), сокращённый отдых (на 15-30 сек), RPE 8-10 (работа в отказ)
- Для натуралов: RPE 7-9 (запас 1-2 повтора для защиты ЦНС)

### Структура тренировок (3-дневный сплит A/B/C)
Каждая тренировка содержит **9 упражнений** (3 базовых + 6 изолирующих), покрывающих все мышечные группы:
- **Тренировка A**: Грудь + Спина + Ноги (базовая)
- **Тренировка B**: Плечи + Руки + Ноги (вспомогательная)
- **Тренировка C**: Грудь (верх) + Спина (ширина) + Задняя цепь

### Интерактивный таймер отдыха
- Круговой SVG-индикатор с обратным отсчётом
- Кнопка **+30 сек** для продления отдыха
- Кнопка **Сброс** для возврата к исходному значению
- Вибрация и звуковой сигнал при завершении
- Авто-старт после отметки подхода выполненным

### RPE и технические подсказки
- Каждый экзерсайз содержит **RPE-метку** (Rate of Perceived Exertion) — индикатор желаемой интенсивности
- Под каждым упражнением — **техническая подсказка** тренера (контрольная техника, дыхание, ключевые точки амплитуды)

### Прогресс-трекинг (localStorage)
- Сохранение завершённых тренировок локально на устройстве
- Статистика: всего тренировок, суммарный объём нагрузки, дата последней сессии
- Экран истории с детализацией каждой тренировки
- Возможность очистить историю

### PWA-функции
- ⚡ **Офлайн-режим** через Service Worker (stale-while-revalidate стратегия)
- 📲 **Установка на домашний экран** (Add to Home Screen) с промптом
- 🎨 **Кастомные иконки** 192×192 и 512×512 (PNG + SVG)
- 📱 **Portrait-ориентация** для мобильного использования
- 🚀 **Standalone режим** — без адресной строки браузера

## Запуск локально

```bash
# Python 3
python -m http.server 8000

# Или Node.js
npx serve

# Откройте http://localhost:8000
```

## Сборка и публикация

PWA не требует сборки — это статические файлы. Просто залейте файлы на любой статический хостинг:
- **GitHub Pages**: закоммитьте в репозиторий → Settings → Pages → Deploy from branch
- **Netlify**: drag-and-drop папки в интерфейс
- **Vercel**: `vercel deploy`

## Структура проекта

```
iron/
├── index.html              # HTML-разметка всех экранов
├── app.js                  # Логика: ACSM-алгоритм, таймер, прогресс
├── style.css               # Тёмная спортивная тема (orange accent)
├── manifest.json           # PWA манифест
├── service-worker.js       # SW с кэшированием stale-while-revalidate
├── README.md               # Документация
└── icons/
    ├── icon.svg            # Векторная иконка
    ├── icon-192.png        # 192x192 для PWA
    └── icon-512.png        # 512x512 для PWA
```

## Технологии
- Vanilla JS (без фреймворков) — быстрый запуск и работа офлайн
- Service Worker API для офлайн-доступа
- Web Storage API (localStorage) для прогресса
- SVG для таймера и иконок
- Web Audio API для звуковых уведомлений
- Vibration API для тактильной обратной связи
