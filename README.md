# GymPro Trainer v3

PWA для evidence-based силовых тренировок. Версия 3 перестаёт угадывать фактический объём и рабочие веса: пользователь записывает каждый подход, включая вес, повторы и RIR, а следующая тренировка строится на реальной производительности.

## Что изменилось

- реальный трекинг **каждого подхода** вместо записи упражнения целиком;
- тоннаж считается как `Σ вес × повторы` по выполненным подходам;
- `RIR` хранится вместе с каждым подходом;
- активная тренировка сохраняется в `localStorage` и восстанавливается после reload;
- прогрессия использует предыдущие результаты, а не универсальные коэффициенты для тренажёров;
- недельный объём является основой планирования, а число упражнений больше не фиксировано на 9;
- добавлены опыт и количество тренировок в неделю;
- упражнения имеют стабильные `id`, мышечные группы и тип;
- Service Worker больше не принудительно перезагружает открытые страницы при обновлении;
- shortcut `?action=new` теперь обрабатывается;
- scientific claims отделены от эвристик персонализации.

## Модель тренировки

```text
профиль + цель + частота
        ↓
недельный объём
        ↓
упражнения по мышечным группам
        ↓
предыдущая производительность
        ↓
вес + диапазон повторений + target RIR
        ↓
фактические подходы
        ↓
авторегуляция следующей тренировки
```

### Данные подхода

```js
{
  weight: 82.5,
  reps: 9,
  rir: 2,
  completedAt: "..."
}
```

Это позволяет считать реальный тоннаж, estimated 1RM, PR и строить будущую прогрессию.

## Evidence-based подход

Приложение не заявляет, что все коэффициенты являются стандартом ACSM. Базовые ориентиры разделены с эвристиками приложения.

- Гипертрофия: ориентир по недельному числу рабочих подходов, умеренный диапазон повторений и RIR около 2.
- Сила: более тяжёлые составные упражнения и более длинный отдых.
- Выносливость: более высокий диапазон повторений и короткий отдых.
- Прогрессия: увеличение веса предлагается после выполнения верхней границы повторений при сохранении целевого RIR.

Актуальные рекомендации ACSM 2026 следует рассматривать как основу, а не как набор обязательных процентов 1ПМ для каждого упражнения.

## Локальные данные

`localStorage` хранит четыре сущности:

- `gympro_profile_v3` — профиль;
- `gympro_plan_v3` — последний сгенерированный план;
- `gympro_active_workout_v3` — незавершённая тренировка;
- `gympro_history_v3` — завершённые тренировки.

Незавершённая тренировка намеренно сохраняется при выходе и после перезагрузки страницы.

## Запуск

```bash
python -m http.server 8000
```

Открыть `http://localhost:8000`.

## Ограничения

Это персональный тренировочный инструмент, а не медицинское устройство или замена квалифицированному тренеру. Стартовые веса являются предложениями; фактическая производительность и техника имеют приоритет.
